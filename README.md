## Maintenance and regression tests

Maintainer: Hamdy Abou El Anein — hamdy.aea@protonmail.com

Install `requirements.txt` in a virtual environment. Run `python3 -m unittest -v` from the repository root. The runnable chapter servers no longer enable the debugger by default. Three tests cover basic routes, HTML escaping and random-number boundary rendering for all four chapters. These are local learning examples, not production deployments. Original chapter organization is retained.
